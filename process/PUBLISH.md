# 发布流程与检查清单

发布前逐条过一遍。依据和条款来源见 [research/content/08-compliance/README.md](../research/content/08-compliance/README.md)。
这不是法律意见；规定和平台规则变化快，用之前核对原文。

## 发布前检查清单

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1 | 用了 TTS 配音：发布时勾选平台的 AI 声明，"必选标签"选「含有AI生成内容」 | TTS 属于需要标识的生成合成内容；2026-05 起发布前必须选一个必选标签 |
| 2 | 视频画面内不加文字声明（项目负责人定，2026-10-23）；第 1 步的平台声明和必选标签照做 | 办法第四条的视频起始画面标识是对服务提供者的要求；发布者是第十条：发布时主动声明并使用平台的标识功能 |
| 3 | 商单：再选「含有营销信息」 | 必选标签之一 |
| 4 | 配乐和音效只用自己合成的，或明确覆盖多平台商用的授权；不用抖音、剪映曲库做站外和商单 | 平台曲库只限站内非商业 |
| 5 | 字体用仓库自带的思源黑体（`vlab.fonts`） | 微软雅黑著作权归方正，见合规研究第 4 节 |
| 6 | 保存源码、参数和渲染记录 | 被 Content ID 误认领时用来申诉；也是证明权属的依据 |
| 7 | 不使用任何"去标识"工具，转码时不刻意清除元数据 | 2026 年清朗行动点名"去标识"工具和教程 |
| 8 | 题材检查：不碰医疗建议、理财、法律意见；不做时政新闻；不画国界和历史疆域；不做可被模仿的危险实验 | 合规研究第 6 节 |

## 发布时

- **剧本已确认**：项目 `SCRIPT.md` 开头是"剧本确认：已确认"，见 [SCRIPT-REVIEW.md](SCRIPT-REVIEW.md)。标题和封面上的字也属于要审的文字。
- **标题和封面**：定稿写进项目 README 的「发布信息」，封面用代码生成，脚本放在项目里，可以重出。
- **B站投稿**：在"创作声明"里选"该视频使用人工智能合成技术"（用了 TTS 配音就选）。
- **字幕**：画面里没烧字幕时，可以把 `build/<id>/subs.srt` 作为外挂字幕上传。
- **没核实的**：B站投稿的视频规格、封面规范、分区和标签，见 `research/content/03-platforms/` 的"还没查"。

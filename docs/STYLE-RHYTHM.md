# 节奏与质检硬指标

这份文档是 `vlab-review` 的判定依据。数值只在这里和 `toolkit/vlab/tools/review.py` 的 `HARD`
字典里各出现一次——改标准就改这两处，别口头约定。

## 为什么要有硬指标

对标片（比特新语这类）和普通 AI 科普片的差距，肉眼能感到，但说不清。拆开看大部分是可量化的：

| 感受 | 可量化的东西 |
|---|---|
| "更密" | 镜头数、平均镜长、单镜 action beat 数 |
| "更稳" | 同款视觉连镜数、公共组件覆盖率 |
| "更有氛围" | 全局特效层数、暗部亮度、颗粒 |
| "更专业" | 逐帧无黑屏/空屏、响度达标 |

把这些写成数字之后，每次出片先跑体检，再谈感觉。

## 片长与优先级

**片长区间 120–360 秒（2–6 分钟）**，不是固定的 3 分钟。

- **在这区间里，时长服从内容**：四分钟才讲得透就四分钟；两分十秒能收干净，就不要注水到三分。
- **两头封口**：低于 2 分钟讲不透一个知识命题（钩子 / 反转 / 原理 / 收束四段至少各 20 秒）；
  高于 6 分钟完播率掉得比“讲得全”划算。
- **第一优先级是观感**。下面所有硬指标（镜长、beat、连镜、响度）都是为观感服务的；
  两者冲突时以观感为准，并在项目 `SCRIPT.md` 里写下为什么破例、破了哪一条。
- 006《对折》是第一条按内容定时长的片子（180.0s / 51 镜）；001–005 是旧标准（60 秒左右），不追溯重做。

**传播优先的时长**：目标区间在 `STYLE-IMPACT.md` 规矩 5 里另有一条（130–170 秒）。
两份冲突时以 `STYLE-IMPACT.md` 为准——120–360 是"能做多长"，130–170 是"做成什么样才有人看"。

## 硬指标表

| 指标 | 阈值 | 含义 |
|---|---|---|
| 片长 | 120–360 s | 2–6 分钟；区间内时长服从内容，不为凑时长注水 |
| 镜头数 | ≥ max(13, ⌈片长 ÷ 5.2⌉) | 短片兜底 13；长片按单镜上限反算：2 分钟 ≥24 镜，6 分钟 ≥70 镜 |
| 单镜最长 | ≤ 5.2 s | 超过 5 秒观众会开始走神，除非有强运镜 |
| 平均镜长 | ≤ 4.5 s | 对标片的实际值在 3.5–4.3 s |
| 单镜 action beat | ≥ 2 | 一个镜头里至少发生两件事（基础画面 1 拍 + 每个词绑定出场 1 拍） |
| 同款视觉连镜 | ≤ 2 | 同一种卡片/模板连续出现不超过 2 镜，否则"一个模板用到底" |
| 公共组件覆盖 | ≥ 80% | 镜头必须由 `toolkit/vlab` 里的卡片/模板/着色器组装，不在项目里一次性写死 |
| 全局特效层 | = 7 | 手持微动、扫光、快门闪、暗场呼吸、颗粒扫描线、星尘底纹、字幕条（字幕条由 finalize 烧 ASS 实现，有 `build/<id>/subs.ass` 就算这一层在） |
| 整片响度 | -14 ±1 LUFS | 平台统一标准 |

`action beat` 的定义值得特别说明：它数的是"画面上发生了多少件事"，不是"元素有多少个"。
一个静态标题卡即使有五行字，也只有 1 拍。绑定到词的出场（`cues`）每命中一次算 1 拍，
因为那一下观众能感到"东西进来了"。

## 逐帧质检

整片抽帧拼图（`vlab-preview`）看整体，逐帧质检（`vlab-review`）抓局部：每个镜头抽首/中/尾三帧（镜长的 10% / 50% / 94%），量三个数。
首帧故意不取 0：镜头都是从暗场/空场进来的，0 帧本来就没东西，拿它判定只会得到假警报。

| 指标 | 判定 | 抓什么问题 |
|---|---|---|
| 平均亮度 < 6 | 几乎全黑 | 渲染失败、黑场、元素没出现 |
| 亮度标准差 < 2.5 | 整帧无内容 | 纯色帧、图层丢失 |
| 边缘占比 < 0.0035 | 缺结构 | 只剩一个光斑，没有可读信息 |

只看静态抽查不够的原因很实在：**坏帧往往只出现在特定的几十帧**——某个 spring 过冲导致元素飞出画面、
某个 canvas 采样在某帧才拿到字体。所以首/中/尾三帧是下限，改完动画要人再抽几帧看。

## 一条片子的完整验收流程

```bash
uv run vlab-build videos/005-emergence/project.yaml      # 增量渲染 + 合配音字幕
uv run vlab-preview videos/005-emergence/renders/005-emergence_emergent.mp4 \
    --timeline videos/005-emergence/build/005-emergence/timeline.json --scenes both   # 整体看
uv run vlab-review videos/005-emergence/project.yaml --loudness                       # 体检
uv run vlab-ab videos/002-mobius-strip/renders/mobius-strip_final.mp4 \
    videos/003-sunset-red/renders/sunset-red_final.mp4 \
    videos/005-emergence/renders/005-emergence_emergent.mp4 \
    --out videos/005-emergence/media/ab_002_003_005.png                                # 和旧片并排比
```

四条都过才算成片。`vlab-review` 退出码非 0 时不要交付。

A/B 图按片长百分比抽帧（默认 15%/50%/85%），比的是同一条情绪曲线的开、中、收，不是同一个绝对秒数。
看图只问一件事：肉眼能不能看出“更密/更有氛围”；看不出就说明还差一个档次，回 `review.py` 的 `HARD` 字典检查差在哪一项。

## 节奏是怎么排出来的

不是先写文案再切镜头，而是反过来：

1. **先定钩子和收尾**，两句话决定整片的情绪曲线。
2. **按硬指标反推镜头数**：目标 62–66 秒 ÷ 4.2 秒 ≈ 15 镜。
3. **每镜一句旁白，字数 ≤ 18 字**（中文配音约 0.236 秒/字，超过就会顶破 5.2 秒）。
4. **把技术手段摊到镜头上**，让相邻两镜的"零件"不同，这一步在 `vlab-review` 里就是同款连镜检查。
5. **配音先出，画面后做**：时长由配音定，画面按 `timeline.json` 的词时间点对齐。

## 特效栈的边界

七层特效是"氛围"，不是"内容"。原则：

- 任何一层关掉，画面信息量不应该减少（只是变得平淡）；
- 字幕条与烧字幕同时开会导致文字重叠，`Shot` 组合里默认关掉字幕条；
- 颗粒和扫描线的强度以"不仔细看看不出来"为准，过重会显得脏；
- **切点不许发亮**：`flash` 层默认全片关闭（`fx_default: {flash: false}`）。
  每镜闪一次白 = 180 秒的片子里五十几次频闪，暗场会从 YAVG 9 被推到 53，
  观众感知到的就是“一闪一闪”。章节标点改用压暗（`dipIn` / `dipOut`，10 帧 0.55）——
  人眼对变暗的容忍度远高于变白。亮场切暗场时，给亮镜末尾加 `dipOut`
  （深度 ≈ 1 − 22/切点前亮度），否则硬切就是一次关灯。
  验收用 `videos/006-fold/media/check/flicker.py`：正向跳变（变亮）>6 的必须为 0，
  负向（变暗）是剪辑呼吸，不设阈值。
- **背景相位跨镜连续**：星尘/扫光/呼吸/手持统一用 `frame + t0`（t0 = 全片起始帧，build 传），
  切镜时背景完全不动，只有内容换。按镜内帧计时的话，120 颗星会在每 3 秒集体换一次亮度。
- 扫光是"一道窄光斜过"，不是常驻灰带：宽度 ≤ 18%、峰值 ≤ 0.05，而且周期里只出现一小段、其余时间隐形。
  36% 宽 / 0.06 峰值时整块画面有三分之一被提亮，暗底上看着像蒙了层脏，连看十几镜很压画面。
- 卡片里的文字和盖上去的元素（印章、框、标注）不能互相吞字：印章只压末字一角，
  压住整个字就成了排版事故。

# 《为什么没有绿色的恒星》长版分镜（6 分 30 秒）

**状态**：存档，不用于制作。成片用的是锁定时间轴的 3 分 30 秒版，见 [script.md](script.md)。
**用途**：以后要做横屏长版（B站母版）时从这里捡回被砍掉的段落。
**事实依据**：[facts.md](facts.md)

长版比 3 分钟版多出来的内容：

| 段落 | 时长 | 内容 |
|---|---|---|
| 铁块加热演示 | 15 秒 | 一块铁从暗红烧到蓝白，温度数字同步滚动。建立"温度决定颜色"的体感 |
| OBAFGKM 光谱型 | 18 秒 | 七个色块依次落位，标注各自的温度区间和颜色，看完自然发现没有绿 |
| 绿色在光谱正中 | 10 秒 | 可见光谱条，红蓝在两端，绿在正中，箭头指向绿色问"它去哪了" |
| 维恩位移定律 | 14 秒 | 公式 λ = b / T 出现，常数 b = 2.897771955×10⁻³ m·K，代入计算 |
| 色度图黑体轨迹 | 14 秒 | 色度图上恒星颜色连成一条线，从红穿过白走向蓝，永远不进纯绿角落 |
| 多处停顿和强调 | 约 60 秒 | 关键句之后留白，反转处重复强调 |

另外长版可以考虑加入（3 分钟版放不下的）：

- **太阳其实是白色的**（约 40 秒）：在大气外看太阳是白的，地面看偏黄是大气散射掉蓝光。这是另一个反直觉点，而且 003 已经做过大气散射，画面能直接复用。
- **历史上的"绿色恒星"误报**（待查）：如果确有记载，是很好的开场钩子。facts.md 里列为待查项。

长版的叙事结构和 3 分钟版相同：钩子 → 直觉 → 反转 → 原理 → 升华，只是每一步铺垫更充分。

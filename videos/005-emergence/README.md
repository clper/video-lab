---

## 讲了什么

一只鸟笨得要命，一群鸟却像有大脑：没有指挥、没有图纸、没有蓝图，只有三条局部规则
（分离、对齐、聚合）。同样的规则在别处也能长出秩序——菌丝长成地铁网、五个细胞演化出滑翔机、
一个数字涨过临界点就崩盘。收尾落在「涌现」这个词上：整体有了，个体却没有。

## 为什么这么做

- **时长由配音定**：先 `vlab-tts` 出词级时间轴，画面按 `timeline.json` 的词时间点对齐，
  不写死秒数（改一句旁白不用改画面）。
- **同一批粒子演两次灾难**：S11 不新写一套模拟，只给 S1 的鸟群加 `collapseAt` 和 `red`，
  同一个系统换个结局——这是这条片子最想表达的东西，也让两镜在视觉上真正"同源"。
- **菌丝和地铁共用一张网**：S5/S6 是同一张生长图，S6 只是把它拉直并换配色。
- **滑翔机不是画上去的**：生命游戏里先跑真实演化，从结果里搜出滑翔机命中的那一代再高亮。

## 怎么重建

```powershell
uv run vlab-build videos/005-emergence/project.yaml              # 增量：旁白/指纹没变就复用
uv run vlab-review videos/005-emergence/project.yaml --loudness  # 硬指标 + 逐帧 + 响度
uv run vlab-preview videos/005-emergence/renders/005-emergence_emergent.mp4 `
    --timeline videos/005-emergence/build/005-emergence/timeline.json --scenes both
```

目录：`content/` 稿子、`shader/` 两个 `.frag`、`styles/emergent.yaml` 风格、
`build/` 配音时间轴字幕、`media/clips/` 分镜片段（入库，克隆后不用重渲）、`renders/` 成片。
画面代码全在 `toolkit/vlab/render/remotion/src/cards/`，这里只写「用哪张卡 + 传什么参数」。

## 踩过的坑（都已在工具里修掉）

| 现象 | 原因 | 修法 |
|---|---|---|
| 成片比配音短 5 秒 | 各渲染器 `time_base` 不同（remotion 1/90000、着色器 1/15360），`-f concat` 按首文件参数解其余文件，最后一镜整段丢帧 | 改 concat 滤镜逐路解码 + 拼接后帧数校验 |
| 抽帧报「61.21s 取不到帧」 | 片尾取帧时间超过实际时长 | 结尾帧按 `min(end-0.12, duration-0.15)` 收 |
| 近景镜头几乎空镜 | 相机公式漏乘缩放（`540-(cx-540)*s` 应为 `540-s*cx`） | `Flock.tsx` 修公式 |
| 收尾金句半句就消失 | 字幕按标点切句、最后一句没铺到片尾 | 末镜整句呈现 + 最后一句停到片尾 |
| 抽帧对照图上有一格整帧灰白 | 切点白闪峰值 0.42、三帧才退 | 降到 0.30 / 两帧，A/B 抽帧同时避开切点 |
| 暗底上一条很宽的斜向灰带 | 扫光层 36% 宽 / 峰值 0.06，且每个镜头全程可见 | 收窄到 16%、峰值 0.05，只在周期前 42% 出现 |
| 印章把末字整个盖住 | 章子 `right:-30` 是往左偏，210px 宽正好压在「飞」上 | 改 `right:-95`，只压末字一角 |
| 13 镜渲到 particleText 卡住十几分钟 | CPU 核多时并发开到十几个，node/chrome 偶发卡死 | 并发封顶 4，超时重试降到 2 |

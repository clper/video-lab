## 0 一句话

1886 年，高尔顿量了 928 个成年子女的身高，发现"极端"不会遗传——它会往回走。
这条统计规律解释了人生里最折磨人的那件事：**最好的一次之后，多半会更差，而那不是你做错了什么。**

**落点（规矩 1 要求的一行，主语必须是"你"）**
> 你最好的那次之后会回落，最差的那次之后会回升。
> 不是因为你骄傲了，也不是因为你终于做对了什么——你只是回到了你自己的那条线。
> **所以：你不必为回落自责，也不必为回升邀功。**

### 4.2 节奏三条硬规矩 + 本片的两处破例

1. **同一张卡最多连用两镜，第三镜必须换卡。** 本片两处例外，都是"连续动作"不是"复用画面"：
   - **B1–B9 连续 scatterRegress（S15–S23，实际九镜）**：这是同一片散点云在长出那条线，每镜换 `mode`
     （intro / points / drift / tall / short / coef / line / push / one）。
     切走就断了"同一片点云"的物性——判据是"画面读法变没变"，不是"卡变没变"。
   - **D2–D8 连续 waveField（S33–S39，七镜，D5  kineticSubtitle 断开）**：同一个海面在起落。
2. **每 20–30 秒要有一处"画面自己演"**：A4 弹珠雨、B2 计数器滚到 928、B8 沿金线推近、C6 销冠柱子跌落、D4/D6 浪吞字。
3. **无字幕的镜头是呼吸，不是空档**：A4、B3、B8、C4、D3、D8 六镜全片无字，都落在四次高潮前后，先把声音收掉再放。

### 4.3 体检指标与本片口径（007 实测后补）

- **action beat 用申报制**：remotion 卡的动作在组件内部，review 数不清，规矩就是作者在 `project.yaml`
  每镜写 `beats: N`（入场动效 + 内容动作）。007 全片已申报（2–3/镜）。

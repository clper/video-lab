# audio：音频研究

**定位**：声音是视频的另一半。这里研究配音、混音、音乐、音效、音画同步，
目标是让每条视频"听起来专业"，并且和代码生成的画面一样：可复现、可自动化、改一处重出一版。

和其他目录的分工：`research/visual/` 研究画面技术；`research/audio/` 研究声音；`research/frontier/` 研究前沿生成模型（其中音视频联合生成两边都会涉及，结论互相引用）。

---

## 现状：仓库里已有的音频能力

| 能力 | 在哪 | 说明 |
|---|---|---|
| 配音 + 词级时间轴 | `toolkit/vlab/pipeline/tts.py`（命令 `vlab-tts`） | Edge TTS，免费、在线；每个词的时间点驱动画面出场 |
| 响度标准化 | `toolkit/vlab/pipeline/tts.py`、`finalize.py` | 配音标准化到 -16 LUFS；单声道原样复制成左右声道（不用 `-ac 2`，避免音量乘 0.707） |
| 字幕 | `vlab-tts` 生成 ASS / SRT | research/visual/11 还做了 RPG 对话框，按词级时间点逐字打出 |
| 程序化音乐和音效 | `research/visual/11-pixel-story/pixel_story.py` | numpy 合成芯片音乐（方波旋律 + 三角波低音）和流星、落地、闪光音效 |
| 混音 | `research/visual/11-pixel-story`（ffmpeg `amix` + `loudnorm`） | 配音和音乐按固定音量混合，说话时音乐不会自动压低 |

已知短板：音乐和音效只有 research/visual/11 一处、没有复用；混音没有自动避让；配音只有 Edge TTS 的固定音色。

## 研究方向（编号 = 以后的实验目录 `research/audio/NN-主题/`）

做法层级的含义见 `docs/VIDEO-TYPES.md` 第四节。

| 编号 | 方向 | 要回答的问题 | 做法 | 层级 | 状态 |
|---|---|---|---|---|---|
| 01 | 配音音色与语气 | 哪些音色适合哪类内容？语速、音调、停顿怎么配？ | Edge TTS 多音色对比；`rate` / `volume` / `pitch` 参数（不支持自定义 SSML） | 纯代码 | 待开始 |
| 02 | 混音规范与自动避让 | 配音、音乐、音效各多响？说话时音乐自动压低 | ffmpeg `sidechaincompress`；定一套 LUFS 规范 | 纯代码 | 待开始 |
| 03 | 程序化背景音乐 | 能否按情绪、时长、节奏自动生成可用的配乐？ | 和弦进行 + 旋律生成 + 合成器音色（从 research/visual/11 的芯片音乐扩展） | 纯代码 | 待开始 |
| 04 | 音效库 | 转场、出现、点击、闪光这类常用音效怎么快速获得？ | 程序化合成；CC0 音效库（如 Kenney；Freesound 每个文件授权不同，需逐个确认） | 代码 + 素材 | 待开始 |
| 05 | 音画同步 | 画面卡音乐节拍、卡配音重音 | 节拍 / 起音检测（如 librosa，需 `uv add`）→ 时间轴 → 驱动画面 | 纯代码 | 待开始 |
| 06 | AI 配音与声音克隆 | 有没有比 Edge TTS 更自然、可定制音色的方案？ | 开源 / 商用 TTS 大模型对比（候选如 CosyVoice、F5-TTS、GPT-SoVITS，以调研时的最新版本为准） | 代码 + 工具 | 待开始 |
| 07 | AI 音乐与音效生成 | 用文字描述生成配乐、音效 | 开源模型（如 MusicGen、Stable Audio Open）和商用服务对比，重点看授权条款 | 代码 + 工具 | 待开始 |
| 08 | 口播素材处理 | 实拍口播的自动字幕、去语气词、降噪 | Whisper 语音识别 + ffmpeg 降噪 | 代码 + 工具 | 待开始 |

**建议顺序**：02 → 01 → 05 → 03 → 04 → 06 → 07 → 08。
前五项是纯代码、本机就能做、马上能用到每条视频里；后三项要引入模型或外部服务，放后面。

## 规则

- **一个实验一个目录**：`research/audio/NN-主题/`，里面放脚本、`README.md`（问题、做法、结论、日期）和 `renders/`（试听样例，入库）。
- **试听样例统一响度**（-16 LUFS），横向比较才公平；每个样例旁边写清参数。
- **只依赖 `toolkit/vlab/`**，不依赖 `videos/`、`research/visual/`、`research/frontier/`。验证成熟、被视频复用的音频工具提升进 `toolkit/vlab/`（预计新开 `toolkit/vlab/audio/`）。
- **素材必须记录来源和授权**：第三方音色、音乐、音效写明出处和授权方式；授权不明的不入库。
- 用到 API 密钥时只放在本地 `.env`（已在 `.gitignore` 里忽略），不写进代码。

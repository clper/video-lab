# 09 事件驱动音效

**日期**：2026-10-21　**状态**：✅ 第一版完成，代码在 `toolkit/vlab/audio/sfx.py`

## 问题

给视频配音效通常是剪辑师一个个手动对位，费时间。我们的画面是代码生成的，**每个画面事件发生在第几秒、是什么动作，代码本来就知道**——
能不能把这份"事件清单"直接变成音效轨，做到和画面严丝合缝、零手工？这是实拍和 AI 生成视频都做不到的优势。

## 做法

1. **音效全部用代码合成**（numpy），没有素材文件、没有版权问题。12 种：

| 音效 | 用在 | 音效 | 用在 |
|---|---|---|---|
| 弹出 pop | 字、图标出现 | 冲击 impact | 重要数字落定、大标题 |
| 回弹 boing | 问号、可爱元素摇摆 | 铃音 chime | 亮点、光、答案揭晓 |
| 呼啸 whoosh | 滑入、转场 | 打字 key | 打字机效果 |
| 甩镜 whip | 快速甩出画面 | 故障 glitch | 故障风文字 |
| 咔嗒 tick | 数字跳动、计时 | 闪烁 shimmer | 魔法、星光出现 |
| 激光 laser | 光线、能量传播 | 上扬 riser | 转场前蓄势 |

同一种音效每次触发略有变化（音高随事件序号微调），连续出现时不机械。

2. **事件清单**：画面脚本按配音的词级时间轴生成，例如

```json
[{"t": 0.80, "kind": "chime", "gain": 0.8}, {"t": 4.71, "kind": "impact", "gain": 0.9}]
```

3. `sfx.render(events, duration)` 把事件排成一条音轨，再由 `vlab.audio.mix` 和配音、配乐按规范混音（见 02）。

## 产出

- `renders/sfx_palette.mp4`：音效样板，12 种逐个播放，每种一张卡片（名称、用途、波形）。
- 实际用例：`research/visual/12-kinetic-type`《光有多快》——每个字弹出、每次转场、数字每跳过一个万位，
  都自动配了音效（事件清单在它的 `build/light-speed/sfx_events.json`），数字滚动越来越慢时"咔嗒"声也跟着变稀。

```
uv run python research/audio/09-event-sfx/sfx_palette.py
```

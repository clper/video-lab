# 02 混音规范与自动避让

**日期**：2026-10-21　**状态**：✅ 第一版完成，规范已落到 `toolkit/vlab/audio/mix.py`（`MIX` 默认值）

## 问题

配音、配乐、音效各该多响？配乐一直开着会盖住旁白，关掉又显得冷清——能不能"说话时自动压低、停下来自动回来"？

## 做法

同一段测试配音（`content/duck-test.json`，四句话，句间有停顿）+ 同一段程序化配乐，混两版：

- **A**：配乐固定 -12 dB，不避让
- **B**：配乐 -12 dB，用配音做侧链（sidechain）自动压低

把"被压低后的配乐"单独导出来，按词级时间轴分成"说话时"和"停顿时"两类时段测有效值电平；两版成片测整体响度和真峰值。

```
uv run python research/audio/02-mix-ducking/ducking_test.py
```

## 混音规范（vlab.audio.mix 的默认值）

| 轨道 | 规范 |
|---|---|
| 配音 | `vlab-tts` 已标准化到 -16 LUFS（单声道），混音时原样使用 |
| 配乐 | -12 dB；说话时稳定压低 8 dB，停顿时约 0.5 秒内回来 |
| 音效 | -6 dB |
| 成片 | 立体声 -14 LUFS，真峰值不超过 -1.5 dBTP（短视频平台常见目标，具体以平台为准） |

## 结果

| 测量 | 不避让 | 自动避让 |
|---|---|---|
| 配乐电平，说话时 | -31.5 dB | -38.1 dB（**压低 6.6 dB**） |
| 配乐电平，停顿时 | -35.3 dB | -36.4 dB（压低 1.1 dB） |
| 成片整体响度 | -14.4 LUFS | -14.2 LUFS |
| 成片真峰值 | -1.4 dBTP | -1.5 dBTP |

曲线见 `renders/ducking_plot.png`：说话时（蓝底）金线稳定比灰线低约 8 dB、形状跟着原配乐走；
平均值 6.6 dB 比 8 dB 小，是因为每句开口的起音（约 20 毫秒）和句末的回升被算进了"说话时"；
停顿时的 1.1 dB 是配乐在 0.5 秒内回升的过程。试听：`renders/A_no_duck.m4a`、`renders/B_duck.m4a`。

响度用两遍标准化（第一遍测量，第二遍按测量值线性调整）：单遍时成片在 -14.5～-14.9 LUFS，两遍后 -14.2～-14.4。
剩下的零点几 dB 来自真峰值上限（-1.5 dBTP）限制了可加的增益，以及 AAC 编码本身，都在平台可接受的范围内。

## 走过的弯路（为什么用"固定深度"）

| 方案 | 现象 | 结论 |
|---|---|---|
| 普通压缩（阈值 0.03、比率 3） | 说话时只压低 4 dB，旁白还是被盖 | 不够 |
| 加大压缩（阈值 0.008、比率 8） | 平均压低 7.7 dB，但曲线显示每句开口时配乐被压到几乎听不见（低二三十 dB），句中又慢慢升回来，听感忽有忽无 | 只看平均值会被骗，必须看曲线 |
| **固定深度**（比率 20 一开口就压住，再只混回 40% 原信号，ffmpeg `sidechaincompress` 的 `mix` 参数） | 说话时稳定低 8 dB，不会被压没，也不忽高忽低 | ✅ 采用；深度用 `depth_db` 调 |

## 用法

```python
from vlab.audio import mix
mix.mux("silent.mp4", "build/x/narration.wav", "renders/x.mp4", music="music.wav", sfx="sfx.wav", duration=20.6)
mix.mix_audio("narration.wav", "out.m4a", music="music.wav", depth_db=10)   # 只出音频；可以覆盖任何默认值
print(mix.loudness("renders/x.mp4"))                                          # (LUFS, 真峰值 dBTP)
```

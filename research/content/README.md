# content：创作内容研究

**定位**：`visual/`、`audio/` 研究"怎么做"，这里研究"做什么、给谁看"：
面向大众有哪些内容方向，账号怎么定位，栏目怎么设，稿子怎么写、怎么核实，发布有哪些合规要求。
这里的结论决定接下来补哪些技术和模板。

**面向大众**：选题、语言、时长都按普通观众来定。观众不关心画面是不是代码画的，只关心好不好看、有没有收获。
（制作揭秘副线例外，见 02。）

## 02 账号定位与栏目（草案）

### 一句话定位（候选，待定）

- **"用代码把看不见的科学画出来"**：突出画面，适合主线。
- **"一分钟，讲明白一个为什么"**：突出短和好懂，适合短视频平台。

调性：好奇、准确、温和，带一点幽默。不夸张，不标题党。

### 栏目候选

按已经验证过的能力拟的，试播后按数据增减。

| 栏目 | 讲什么 | 例子 | 主画面 | 已有基础 |
|---|---|---|---|---|
| 「为什么」日常科学 | 生活里常见现象背后的原理 | 夕阳为什么是红的、天为什么是蓝的 | 着色器空镜 + Manim | 003 |
| 「数学之美」 | 反直觉又好看的数学对象 | 莫比乌斯环、分形 | Manim | 002、research/visual/10 |
| 「计算机冷知识」 | 天天在用、却说不清的计算机原理 | 0.1 + 0.2 为什么不等于 0.3 | Manim + 信息图 | 001 |
| 「像素童话」 | 小柚和阿团的系列小故事 | 掉落的星星 | 像素风 | research/visual/11 |
| 「一分钟看懂」 | 一个数字、一组数据讲清一件事 | 光有多快 | 信息图模板 + 文字动效 | research/visual/08、12 |

### 双线策略

- **主线**：面向大众的科普成片，也就是上面的栏目。
- **副线**：制作揭秘，比如"我用代码画出了夕阳为什么是红的"，展示代码、渲染过程和成片对比。
  "用代码画视频"本身是稀缺内容，B 站科技区和开发者圈子有天然受众。
- **互相导流**：副线结尾引到主线成片；主线简介写明画面怎么做的，顺带满足 08 的标识要求。

## 04 选题标准（草案）

每项 0–2 分，满分 14 分，**9 分以上再做**。

| 标准 | 2 分 | 0 分 |
|---|---|---|
| 好奇心 | 一句话就能让人"咦？"（反直觉、常见但说不清） | 大家早就知道，或者根本不关心 |
| 画面优势 | 动画讲比真人讲、比图片讲明显更清楚 | 换成口播也一样 |
| 一分钟讲得清 | 核心原理 60 秒内讲完 | 必须铺垫很多前置知识（可以拆成系列） |
| 和生活相关 | 日常现象、常识、正在热议的话题 | 只有专业人士在意 |
| 可核实 | 有教科书、权威机构或论文可查，数字能核对 | 说法众说纷纭、没有可靠来源 |
| 制作成本 | 能用现成模板和画面风格 | 要从零开发新技术 |
| 可系列化 | 能归进某个栏目，还有下一期 | 一次性题目 |

## 05 叙事模板（草案）

| 类型 | 结构 | 例子 |
|---|---|---|
| 科普 | **钩子**（前 3 秒，一个问题或反常识画面）→ **直觉**（大家通常怎么想）→ **反转**（为什么不对）→ **原理**（一步一个画面）→ **升华**（联系生活，留一个问题） | 003 夕阳为什么是红的 |
| 数字快讯 | 数字冲击开场 → 换算成生活里的尺度 → 一个反差 → 结论 | research/visual/12 光有多快 |
| 故事 | **建立**（角色和世界）→ **冲突**（想要什么、遇到什么）→ **解决**（变化、温暖的结尾） | research/visual/11 掉落的星星 |
| 音乐视频 | 按段落切画面：前奏建立氛围，主歌铺陈，副歌换景、加强视觉，节拍点卡转场 | 待做 |

写稿时的硬约束：每句话对应一个画面；画面跟着词走（`timeline.json`）；前 3 秒必须出现钩子，不放片头 Logo。

## 06 文案和核实（草案）

1. **AI 起草**：按 05 的模板写稿，标出每一个事实和数字。
2. **逐条核实**：每个事实找一个可靠来源（教科书、权威机构、论文、官方数据），记录在稿子旁的 `facts.md`：说法、来源链接、查证日期。
3. **数字自己算一遍**：比如"一秒绕地球七圈半"，按 300000 ÷ 40075 ≈ 7.49 验算；"八分多钟"，按日地距离 ÷ 光速 ≈ 499 秒验算。
4. **人工通读**：通读一遍再配音。配音后改稿要重渲染，所以核实必须在配音之前做完。
5. **简化要标明**：为了好懂做了简化的地方（比如光速取 30 万公里/秒），画面上加一行小字注明精确值。

可信度是长期积累的资产，一条错误会抵消很多条正确。

## 规则

- **结论带日期和来源**：平台规则、法规、数据变化很快。写明查证日期和链接；超过半年的结论，用之前重新核实。
- **方向和栏目以数据为准**：试播后按完播率、互动、涨粉调整，不靠感觉。
- **先过合规再动手**：涉及音乐、他人作品、真人形象的选题，先按 08 检查。

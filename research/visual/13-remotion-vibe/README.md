# 13-remotion-vibe：15 秒 Remotion 样片（决策闸门）

对标 B 站「比特新语 / Vibe 知识」的观感，验证 Remotion 路线能不能打。
这不是正式作品，只用来回答一个问题：**按这套设计系统和全局特效，画面是否明显比 002/003 更"精致"？**

## 产出

- 渲染代码在 `toolkit/vlab/render/remotion/`（可复用资产，不放在这里）。
- 成片：`research/visual/13-remotion-vibe/renders/sample15s.mp4`（1080×1920 / 30fps / 15s）。

## 样片内容

| 时间 | 镜头卡 | 内容 |
|---|---|---|
| 0.0–3.0s | 粒子聚字 | 760 粒子从四周飞入，聚成「涌现」 |
| 3.0–6.5s | 科技卡 | 三条规则卡依次落位并轮流点亮 |
| 6.5–9.5s | 数字滚动 | 640 只鸟 / 0 个指挥 |
| 9.5–12.5s | 线条生长 | 金色分叉网 → 青色地铁线 |
| 12.5–15.0s | 逐词字幕 | 金句逐字弹出，关键词高亮 |

## 七层全局特效

手持微动、扫光、快门闪、暗场呼吸、颗粒扫描线、星尘底纹、字幕条。
每一层都能在 `GlobalFX` 的 `layers` 里单独关掉。

| 项 | 结果 |

## 首轮自检发现并修掉的问题

1. **扫描线过重**：文字上出现明显横纹，透明度 0.45 → 0.2，线条 alpha 0.16 → 0.10。
2. **扫光硬边太亮**：带宽 42% → 36%，中心亮度 0.11 → 0.06，周期 110 → 130 帧。
3. **字幕条横线穿过标题**：删除通栏横线，改成名牌下方的短下划线。
4. **粒子云与文字错位**：采样字号 220 → 200 与正文字号一致，粒子中心 900 → 1055 对齐字心。
5. **字幕在逗号处乱折行且收尾太慢**：按逗号强制断行（两行分别是「你无法从一只鸟，」「读出整个鸟群。」），语速 6 → 10 字/秒，整句多留约 1 秒。

## 怎么渲染

```powershell
cd toolkit/vlab/render/remotion
npm install
npx remotion render src/index.ts Sample15s <输出路径> --codec=h264
```

`npm install` 会自动把 `toolkit/vlab/assets/fonts/` 里的思源黑体同步到 `public/fonts/`（不入库）。

## 闸门判断

- 达到/接近预期：进入阶段 2，把卡片库扩到 12–15 张，并接入 videokit。
- 明显不达标：回退方案 B，在现有 Manim/HyperFrames/Pillow 上补动效，不引入 Node 工具链。
